# Área Temporal de Generación (`_generation`)

> **Nota:** Este directorio es un espacio de trabajo **temporal y efímero**. Solo existe y se utiliza mientras la generación de contenido de una Chronicle esté en ejecución activa. Una vez que la Chronicle pasa todos los gates de auditoría y es aprobada, su contenido pasa definitivamente a `content/subjects/` y los artefactos temporales de generación pueden ser archivados o limpiados.

## Estructura por Chronicle en Generación
```
content/_generation/
└── <CHRONICLE-CODE>/
    ├── roadmap.md              # Estado del pipeline de generación (única fuente de verdad de avance)
    └── matriz-trazabilidad.md  # Términos, conceptos, profundidad y mapeo al syllabus maestro
```
